# Hand Detect ✋

Real-time hand number detection directly in the browser.

### Features
- MediaPipe Hands detection
- Recognizes 0–5 fingers
- Indonesian voice output: “satu”, “dua”, etc.
- Live confidence and FPS
- Responsive glass UI
- No backend or API key
- Vercel-ready

### Run
Deploy to Vercel and allow camera access. Camera APIs require HTTPS or localhost.

### Stack
HTML · CSS · JavaScript · MediaPipe Hands · Web Speech API

Camera frames are processed in the browser and are not uploaded to this project server.
